1. このシステムでできること

下請け業者さんが、現場に貼ってあるQRコードをスマホで読み取るだけで、その日の 人数・作業内容・施工面積・写真を送れます。送られた内容は元請の管理画面にすぐ集まるので、 Excelへの手入力が要らなくなります。業者さん側にID・パスワードは必要ありません。

PART 1

管理者編（パソコン）

元請の担当者が使う画面です。パソコンのブラウザで操作します。

2-1. ログインする

  1. ブラウザで https://genba-nippo.higgsfield.app/admin を開きます。
  2. 管理者パスワードを入れて「ログイン」を押します。
一度ログインすると30日間はそのまま使えます。共用パソコンの場合は、使い終わったら右上の「ログアウト」を押してください。
パスワードは管理者で共有する1つだけです。外部に漏れると日報データが見られてしまうため、取り扱いにご注意ください。

2-2.【最初に1回】業者を登録する

日報を出す下請け業者さんの一覧を登録します。上のメニューから「業者マスタ」を開きます。

1件ずつ登録する

  1. 名称に業者名を入れます（例：○○建設）。
  2. 表示順を入れます（次で説明します。分からなければ 0 のままでOK）。
  3. 「追加」を押すと下の一覧に加わります。

「表示順」とは？

業者さんのスマホ画面で、業者名が並ぶ順番を決める数字です。 数字が小さいものほど上（先）に出ます。同じ数字どうしは名前順に並びます。
表示順業者名スマホでの並び
10山田建設1番目に出る
20鈴木工業2番目に出る
30佐藤土木3番目に出る
おすすめの決め方：1・2・3ではなく10・20・30…と10とびで付けると、あとから間に業者が増えたときに 15 を入れるだけで済みます（他を付け直さなくてよい）。
よく日報を出す業者さんを小さい数字にしておくと、現場での選択が早くなります。順番にこだわらない場合は全部 0 のままでも問題ありません（その場合は名前順に並びます）。工種マスタの表示順も考え方は同じです。

Excelでまとめて登録する

業者が何十社もある場合は、Excelの一覧から一括で登録できます。

  1. 「様式をダウンロード」を押して、ひな形ファイルを保存します（Excelでそのまま開けます）。
  2. A列に業者名、B列に表示順（空でも可）を入力して保存します。
  3. 「Excelから業者を一括登録」を押してファイルを選びます。
  4. 確認画面で内容を見て「○件を登録する」を押します。
項目説明
使えるファイル.xlsx / .xls / .csv（ExcelのCSVでも文字化けしません）
見出し行1行目が「業者名」などの見出しなら自動で読み飛ばします
重複すでに登録済みの同じ名前は自動でとばします（二重登録されません）
不備のある行確認画面で赤く表示され、その行だけ登録されません
件数一度に500行まで
業者が増えたときは、前回の表に追記して丸ごと投げ直すだけでOKです。すでにある分は自動でとばされ、増えた分だけ登録されます。

登録した後で直す・使わなくなったとき

  • 編集：名前や表示順を変えられます。
  • 「有効」のチェックを外す：業者さんの選択画面に出なくなります。過去の日報はそのまま残ります。取引が終わった業者はこれを使ってください。
  • 削除：完全に消します。日報で1件でも使われている業者は削除できません（誤って履歴が消えないようにするためです）。その場合は「有効」を外してください。

2-3.【最初に1回】作業内容（工種）を整える

「工種マスタ」は、業者さんが日報でタップして選ぶ作業内容のボタンの一覧です。 掘削・舗装工など、よく使う10種類が最初から入っています。会社に合わせて足したり消したりしてください。

ここにない作業内容は、業者さんが日報の「その他」から自由に入力できます。よく「その他」で同じ言葉が入ってくるようなら、ここに追加すると入力が早くなります。

2-4. 現場をつくる → QRコードを配る

上のメニューから「現場管理」を開きます。

  1. 現場名を入れます（業者さんのスマホ画面の一番上に出ます。取り違え防止のため分かりやすい名前を推奨）。
  2. 住所・総施工面積は任意です（面積は後から入れてもOK）。
  3. 「作成してQRを表示」を押すと、その場でQRコードとURLが出ます。
  4. 「A6印刷ビュー」を押すと印刷用の紙面が開きます。印刷して詰所やゲートに掲示してください。
  5. URLだけLINE等で配りたいときは「URLをコピー」を使います。
現場が多いときは「Excelから現場を一括登録」で一度に作れます（A列＝現場名、B列＝住所、C列＝総施工面積）。QR用のURLは1件ずつ自動で発行されるので、あとから各現場の詳細ページで印刷できます。
URLの取り扱い：このURLを知っている人は誰でもその現場に日報を送れます（ログイン不要のため）。SNSなど不特定多数の目に触れる場所には貼らないでください。万一漏れたときは、現場詳細の「トークン再発行」で古いURLを無効にできます。

2-5. 図面の色塗りを使う場合の準備

業者さんが図面を指でなぞって施工面積を出せる機能です。使う場合は現場詳細ページで次の3つを設定します。3つ揃うと業者さんの画面にボタンが出ます。

  1. 総施工面積を入れて「保存」（進捗率の分母になります）。
  2. 図面をアップロード：PDFでも写真でもOKです（10MBまで）。自動で表示用に変換されます。
  3. 縮尺を設定：図面の中で実際の長さが分かる2点（寸法線の両端など）を順にクリックし、その実寸をメートルで入力して保存します。
「✓図面／✓縮尺／✓総施工面積」の3つのしるしが緑になれば準備完了です。1つでも足りないと、業者さんの画面に色塗りボタンは表示されません。
縮尺の2点はできるだけ離れた2点を選ぶと精度が上がります。近い2点だと、わずかなクリックのずれが面積の大きな誤差になります。

2-6. 毎日の確認（ダッシュボード）

ログインすると最初に出る画面です。その日の提出状況がひと目で分かります。

  • 上の4つの数字：その日の日報件数・延べ人数・施工面積・提出のあった現場数
  • 下の一覧：稼働中の現場ごとに、「未提出」（オレンジ）か、提出済みなら業者名・人数・作業内容
  • 右上の日付を変えると、過去の日の状況も確認できます
夕方にこの画面を開き、オレンジの「未提出」が残っている現場にだけ連絡すれば済みます。

2-7. 日報を見る・直す・消す

  • 絞り込み：開始日・終了日・現場・業者・工種を選んで「絞り込む」（初期表示は今月）
  • 写真：「1枚」などの青い文字を押すと写真が開きます
  • 編集：日付・業者・人数・作業内容・面積・備考を直せます（業者さんの入力ミスの訂正用）
  • 削除：日報と写真をまとめて消します。元に戻せません

2-8. Excelに出す（CSV出力）

  1. 日報一覧で、出したい期間・現場・業者などを絞り込みます。
  2. 「CSV出力」を押すとファイルがダウンロードされます。
  3. ダブルクリックするとExcelで開きます。

出力される列：日付／現場名／業者名／人数／作業内容／施工面積(m2)／備考／提出日時

日本語が文字化けしない形式で出力しているので、そのままExcelで開けます。請求書や出来高の集計にコピーしてお使いください。

2-9. 月ごとに集計する

  • 対象月を選ぶと、その月の日報件数・延べ人数・施工面積が集計されます
  • 現場別／業者別／工種別をボタンで切り替えられます
  • それぞれCSV出力できます
延べ人数とは、日報の人数を足し合わせた数です。例：3人が5日間なら延べ15人。

2-10. 進み具合（進捗率）を見る

図面の色塗りを使っている現場では、現場詳細ページの下に図面に全員の塗りを重ねた図と進捗率が出ます。

  • 塗り済み面積：これまでに塗られた範囲の合計（重なった部分は1回だけ数えます）
  • 進捗率 ＝ 塗り済み面積 ÷ 総施工面積
  • 下の表で、いつ・どの業者が・何m²塗ったかを確認できます
面積はあくまで概算です。塗り方の太さや縮尺設定の精度で誤差が出ます。正式な出来高数量には、実測値を日報一覧の「編集」で上書きしてお使いください。

2-11. 現場が終わったら

  1. 現場詳細ページの「現場を終了する」を押します。
  2. 確認画面で「終了する」を押すと、その現場のURLはすぐ使えなくなります。

業者さんが古いQRを読み込んでも「この現場の日報受付は終了しました」と表示され、送信できません。 終了した現場は現場一覧の「終了」タブに移ります。日報データ・写真・集計はそのまま残ります。

間違えて終了した場合や工期が延びた場合は、「受付を再開する」で元に戻せます（QRはそのまま使えます）。

2-12. その他の設定・困ったとき

古い写真の一括削除

写真の保存容量が心配になったときに使います。終了から180日を超えた現場の写真だけを消します。 「削除対象を確認する」で件数を確認してから実行してください。日報のデータ（人数・作業内容・面積・備考）は残るので、集計やCSVには影響しません。

QRを配り直したいとき（トークン再発行）

URLが外部に漏れたときなどは、現場詳細の「トークン再発行」で新しいURLを発行できます。 古いQR・古いURLは使えなくなるので、必ず新しいQRを印刷して貼り替えてください。

よくある質問（管理者向け）

同じ業者から同じ日に2件届いた

午前・午後で分けて出した場合などに起こります。業者さんの画面では「同じ日の日報があります」と警告が出ますが、あえて追加送信もできる仕様です。不要なら日報一覧から削除してください。

業者さんが「送れない」と言っている

まず現場が「終了」になっていないか確認してください。次にQRが古いもの（トークン再発行後）でないか確認します。どちらも問題なければ電波状況の可能性が高いです。入力内容はスマホに残るので、電波の良い場所で「再送する」を押すよう伝えてください。

業者を間違えて送られた

日報一覧の「編集」で業者を正しいものに変更できます。

パスワードを変えたい

システムの設定変更が必要です。開発担当者にご連絡ください。

PART 2

下請け業者編（スマホ）

現場で作業をされる業者さん向けです。このページだけを印刷して配布できます。

3-1. 準備はいりません

アプリのインストールも、ID・パスワードの登録も不要です。 現場に貼ってあるQRコードをスマホのカメラで読み取るだけで、入力画面が開きます。
  1. スマホのカメラを起動します。
  2. 詰所などに貼ってあるQRコードにカメラを向けます。
  3. 画面に出てきたリンクをタップすると入力画面が開きます。
QRが読めないときは、掲示物の下に書かれているURLを直接入力しても開けます。

3-2. ホーム画面に追加すると次から早い

初回に「ホーム画面に追加すると便利です」という案内が出ます。追加しておくと、次からはQRを読まなくてもアイコンをタップするだけでその現場の日報を開けます。

  • iPhone：画面下の「共有」ボタン → 「ホーム画面に追加」
  • Android：案内の「追加する」ボタン、またはメニューから「ホーム画面に追加」
案内を閉じると次からは出ません。あとから追加したい場合は上記の手順で追加できます。

3-3. 日報の出し方（6ステップ）

入力は1画面で完結します。慣れれば1分もかかりません。

  1. 現場名を確認します。画面の一番上（青い帯）に出ています。ここが違っていたら送らないでください。
  2. 日付は今日の日付が最初から入っています。前の日の分を出すときだけ変更します。
  3. 業者をタップして自分の会社を選びます。名前の一部を入力して探すこともできます。
    ※一度選ぶと次回から自動で入ります。
  4. 人数を「＋」「−」で合わせます（直接入力もできます）。
  5. 作業内容を選びます。一覧にないときは「その他」を押して文字で入力します。
  6. 下の青い「送信する」を押します。

送信すると確認画面が出ます。内容を確かめてください。続けて別の日報を出すときは「続けて入力」を押すと、業者名はそのままで新しい入力ができます。

施工面積と備考は任意です。面積を入れずに送ろうとすると「面積なしで送信しますか?」と確認が出ます。分からなければ、そのまま送信して構いません。
同じ現場・同じ業者・同じ日付ですでに日報が出ていると「同じ日の日報があります」と警告が出ます。午前・午後で分けて出す場合などはそのまま送信できます。

3-4. 写真をつける

  1. 「写真」のカメラのマークをタップします。
  2. その場で撮るか、アルバムから選びます（複数選択可・最大10枚）。
  3. 自動で小さく圧縮されるので、通信量はほとんどかかりません。
  4. 間違えたときは写真の右上の「×」で消せます。

3-5. 図面を塗って面積を出す

現場によっては「図面を塗って面積を測る」というボタンが出ます。その日に施工した範囲を指でなぞると、おおよその面積（m²）が自動で計算されます。

  1. 「図面を塗って面積を測る」をタップします。
  2. 1本指でなぞると塗れます。2本指で図面の移動・拡大縮小ができます。
  3. 下のボタンでペン／消しゴム、太さ（S・M・L）を切り替えられます。
  4. 間違えたら「戻す」（1つ前に戻る）か「全消し」。「全体表示」で図面全体に戻ります。
  5. 画面下に出ている概算面積を確認し、「この面積を使う」を押します。
  6. 施工面積の欄に数字が自動で入ります。あとは通常どおり送信してください。
薄い赤色で表示されている部分は、他の業者さんや別の日にすでに塗られた範囲です。二重に塗らないための目印にしてください。
面積はおおよその値です。実測値が分かっている場合は、施工面積の欄を手で書き換えて送ってください。

3-6. 送信できないとき

電波の悪い現場では送信に失敗することがあります。その場合入力した内容はスマホに保存されますので、書き直す必要はありません。

  1. 赤いメッセージが出たら、電波の良い場所へ移動します。
  2. 画面下のボタンが「再送する」に変わっているので、これを押します。
  3. 画面を閉じてしまった場合も、もう一度QRから開けば入力内容が復元されます（「前回送信できなかった内容を復元しました」と表示されます）。
「この現場の日報受付は終了しました」と出た場合は、その現場が終了になっています。元請の担当者にご連絡ください。

3-7. よくある質問（業者さん向け）

間違えて送ってしまいました

送った内容はご自身では消せません。元請の担当者にご連絡ください。管理画面から修正・削除ができます。

同じ日に2回送ってもいいですか？

問題ありません。午前・午後で分ける、作業内容ごとに分けるといった使い方ができます。警告が出ますが、そのまま送信して構いません。

施工面積が分かりません

空欄のままで送信できます。確認画面で「このまま送信」を押してください。

会社名が一覧にありません

元請の担当者にご連絡ください。業者マスタに追加してもらう必要があります。

通信量やギガは大丈夫ですか？

写真は自動で小さく圧縮してから送るため、1枚あたり数十KB程度です。ほとんど影響しません。

前と違う現場のQRを読んでしまいました

画面の一番上に出ている現場名を必ず確認してください。違っていたら、正しい現場のQRを読み直してください。

4. 用語集

用語意味

工種作業内容の種類（掘削・舗装工など）。日報でタップして選ぶボタンになる
延べ人数日報の人数を合計した数。3人×5日＝延べ15人
マスタあらかじめ登録しておく一覧のこと（業者マスタ＝業者の一覧）
トークン現場ごとのURLに含まれる、推測できない長い文字列。これが鍵の役割をしている
トークン再発行現場のURLを新しくすること。古いQR・URLは使えなくなる
稼働中／終了現場の状態。「終了」にするとその現場のURLは使えなくなる
CSVExcelで開ける表形式のファイル。日報一覧や集計から出力できる
総施工面積その現場全体の施工面積。進捗率を計算するときの分母になる
