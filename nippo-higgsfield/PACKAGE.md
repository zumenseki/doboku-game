# 現場日報 システム一式（引き継ぎ・共有用パッケージ）

このZIPには、稼働中の「現場日報」システムの**全ソースコードと操作マニュアル**が入っています。

---

## 1. まず知っておくこと ― 他のパソコンで使うだけなら、このZIPは不要です

システムは**インターネット上で動いています**。他のパソコンから使いたいだけであれば、
ブラウザで次のURLを開き、管理者パスワードを入れるだけです。インストールは要りません。

| 用途 | URL |
| --- | --- |
| 管理画面（元請の担当者） | https://genba-nippo.higgsfield.app/admin |
| 日報入力（下請け業者） | 現場ごとのQR／URL（管理画面で発行） |

**このZIPが必要になるのは次のような場合です。**

- システムの中身を保管しておきたい（バックアップ・引き継ぎ）
- 別の会社・別の環境で同じものを立ち上げ直したい
- 開発担当者に改修を依頼したい

## 3. 技術的なしくみ（開発担当者向け）

| 項目 | 内容 |
| --- | --- |
| 画面・サーバ | React 19 + TanStack Start（サーバ側レンダリング） |
| 実行環境 | Cloudflare Worker（1つのWorkerで完結） |
| データベース | Cloudflare D1（SQLite互換） |
| 写真・図面の保管 | Cloudflare R2（Worker経由で認可付き配信） |
| 管理者認証 | パスワード + HMAC署名Cookie（30日） |
| 下請け側の認証 | なし。現場ごとの推測不能URL（nanoid 21文字≒126bit）のみ |
| 入力チェック | zod（画面側・サーバ側の両方） |

### 主なファイル

| パス | 役割 |
| --- | --- |
| `app/src/routes/r/$token.tsx` | 下請けの日報入力画面（1画面完結） |
| `app/src/routes/admin/*` | 管理画面（ダッシュボード・日報・集計・現場・マスタ・設定） |
| `app/src/routes/api/r*` | 下請け側API（現場取得・写真・色塗り・日報登録） |
| `app/src/routes/api/admin/*` | 管理側API（要ログイン） |
| `app/src/nippo/server/core.server.ts` | DB/R2アクセス・トークン解決・認証・レート制限 |
| `app/src/nippo/paint.tsx` | 図面色塗りキャンバス（面積の概算計算） |
| `app/src/nippo/import-excel.tsx` | 業者・現場のExcel一括インポート |
| `app/migrations/*.sql` | テーブル定義（追加のみ・破壊的変更なし） |

### 必要な環境変数（シークレット）

| 名前 | 用途 |
| --- | --- |
| `ADMIN_PASSWORD` | 管理画面のログインパスワード |
| `SESSION_SECRET` | ログインCookieの署名鍵（推測不能な長い文字列） |

※ このZIPにパスワードなどの秘密情報は**含まれていません**。別途お伝えしている管理者パスワードをご利用ください。

### 別の環境で動かす場合

1. Cloudflare（Workers + D1 + R2）を用意する
2. `app/` で `bun install` → `bun run build`
3. `app/migrations/*.sql` を D1 に適用
4. `ADMIN_PASSWORD` / `SESSION_SECRET` をシークレットとして登録
5. Worker としてデプロイ（`app/wrangler.jsonc` はビルド用の雛形）

## 4. データはどこにあるか

| データ | 保管場所 | 取り出し方 |
| --- | --- | --- |
| 日報・業者・現場・工種 | Cloudflare D1（データベース） | 管理画面から**CSV出力**（Excelで開けます） |
| 写真・図面・色塗り | Cloudflare R2（ファイル保管） | 管理画面の日報一覧・現場詳細から閲覧 |

**日々のバックアップは、管理画面の「日報一覧 → CSV出力」で十分です。**
月末に当月分をCSVで保存しておけば、記録は手元に残ります。

---

## 5. マニュアルPDFを作り直したいとき

画面を改修してマニュアルの写真が古くなったら、`manual/build.sh` で作り直せます。
本番サイトから自動で画面写真を撮り直し、PDFを生成します（実行にはCloudflare側の権限が必要です）。

```bash
TOKEN=<リポジトリのトークン> ADMIN_PW=<管理者パスワード> bash manual/build.sh
```

---

## 6. 注意事項

- **現場ごとのURLは「鍵」です。** 知っている人は誰でもその現場に日報を送れます。
  SNSなど公開の場に貼らないでください。漏れたときは管理画面の「トークン再発行」で無効化できます。
- **管理者パスワードは共有の1つだけです。** 退職者が出た場合などは変更をご検討ください（開発担当者に依頼）。
- **図面の色塗りで出る面積は概算です。** 正式な出来高数量には実測値を使い、必要なら日報一覧の「編集」で上書きしてください。
- 全ページ検索避け（noindex）を設定しています。検索結果には出ません。
